# Tests

Folder zawiera skrypt automatyzujący proces zakupowy w sklepie PrestaShop. Testuje dodawanie produktów, wyszukiwanie, rejestrację, składanie zamówienia oraz generowanie faktury.

## Pliki
* `tests.py` - Główny skrypt testowy.
* `requirements.txt` - Lista wymaganych bibliotek.

## Instalacja

1. Otwórz terminal w folderze `Tests`.
2. Zainstaluj wymagane biblioteki komendą:

```bash
pip install -r requirements.txt
```
3. Uruchom testy komendą:
```bash
python tests.py
```
