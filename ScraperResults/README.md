# ScraperResults

Ten folder zawiera kompletny zbiór danych pobranych ze sklepu źródłowego, gotowy do masowego importu do Prestashop za pomocą skryptów API.

---

## Struktura i Zawartość

### 1. `categories/`
Zawiera hierarchiczną strukturę folderów, gdzie nazwy folderów reprezentują nazwy kategorii.

* **products.json**: Plik JSON znajdujący się w każdej podkategorii, zawierający listę przynależących do niej produktów.

### 2. `images/`
Zawiera wszystkie pobrane zdjęcia produktów.
